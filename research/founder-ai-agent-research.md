# Founder AI Agent — Research Report

## Purpose

Founder AI agents describe systems where artificial intelligence performs defined tasks autonomously or semi-autonomously to increase founder capability.

The objective is creating scalable execution support.

## Core Principles

An AI agent should:

- Have a clear goal.
- Use defined tools.
- Follow boundaries.
- Produce measurable outcomes.
- Allow human oversight.

## AI Agent Roles

## Research Agent

Supports:

- Market research.
- Competitor analysis.
- Trend monitoring.
- Information organization.

## Content Agent

Supports:

- Drafting.
- Editing.
- Content workflows.
- Distribution preparation.

## Product Agent

Supports:

- Requirements analysis.
- Documentation.
- Testing support.
- Development assistance.

## Operations Agent

Supports:

- Workflow automation.
- Reporting.
- Data processing.
- Task coordination.

## Customer Agent

Supports:

- Support responses.
- Feedback classification.
- Customer insights.

## Agent Design Principles

Good agents require:

### Clear Scope

Define:

- What the agent does.
- What it does not do.

### Reliable Inputs

Provide:

- Quality data.
- Clear context.
- Updated information.

### Verification

Important outputs should be reviewed.

## Founder + Agent Model

Founder:

- Direction.
- Strategy.
- Judgment.
- Final decisions.

AI Agent:

- Execution support.
- Research.
- Automation.
- Scale.

## Common Mistakes

- Creating agents without clear tasks.
- Giving unlimited authority.
- Ignoring verification.
- Automating bad processes.

## Founder Academy Standard

AI agents should extend founder capability while keeping strategic responsibility human.
