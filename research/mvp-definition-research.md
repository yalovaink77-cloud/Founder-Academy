# MVP Definition — Research Report

## Purpose

A Minimum Viable Product (MVP) is the smallest experiment capable of testing one critical business assumption with real customers.

The objective is learning, not shipping.

## Core Principles

An MVP should answer one important question.

Examples:

- Does the customer have the problem?
- Does the solution create value?
- Will customers use it?
- Will customers return?
- Will customers pay?

## MVP Types

- Landing page
- Demo video
- Clickable prototype
- Concierge MVP
- Wizard of Oz MVP
- Manual service
- Limited beta
- Paid pilot
- Pre-order

Different assumptions require different MVPs.

## MVP Success

An MVP succeeds when it produces validated learning.

An MVP fails when it produces no meaningful learning.

## Common Mistakes

- Building too much.
- Testing multiple assumptions simultaneously.
- Measuring vanity metrics.
- Treating MVP as a low-quality product.
- Continuing after learning is complete.

## Founder Academy Standard

Every MVP should have:

- One hypothesis
- One primary metric
- One success threshold
- One failure threshold
- One decision

## Actionable Workflow

1. Identify the riskiest assumption.
2. Select the smallest experiment.
3. Define success criteria.
4. Test with real customers.
5. Measure behaviour.
6. Decide:
   - Continue
   - Iterate
   - Pivot
   - Stop
