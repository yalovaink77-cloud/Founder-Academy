# Founder Network — Research Report

## Purpose

A founder network provides access to knowledge, opportunities, feedback, partnerships, and support that improve startup execution.

The objective is increasing learning speed and reducing isolation.

## Core Principles

A valuable network is built through:

- Giving value.
- Building trust.
- Sharing knowledge.
- Creating meaningful relationships.

## Network Types

## Customer Network

Purpose:

- Understand problems.
- Discover opportunities.
- Validate assumptions.

## Founder Network

Purpose:

- Share experiences.
- Learn from mistakes.
- Exchange strategies.

## Expert Network

Purpose:

- Access specialized knowledge.
- Avoid expensive mistakes.

Examples:

- Legal.
- Finance.
- Technology.
- Marketing.

## Investor Network

Purpose:

- Understand capital.
- Build relationships.
- Prepare future fundraising.

## Community Network

Purpose:

- Distribution.
- Partnerships.
- Collaboration.

## Building Relationships

Effective approaches:

- Help before asking.
- Share useful knowledge.
- Follow up consistently.
- Respect people's time.

## Common Mistakes

- Networking only when needing something.
- Collecting contacts without relationships.
- Ignoring existing communities.
- Focusing only on status.

## Founder Academy Standard

A founder network is a long-term strategic asset built through trust.
