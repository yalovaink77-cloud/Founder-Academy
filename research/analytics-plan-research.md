# Analytics Plan — Research Report

## Purpose

An analytics plan defines what data should be collected, why it matters, and how it supports business decisions.

The objective is not collecting more data.

The objective is making better decisions.

## Core Principles

Analytics should connect:

- User behaviour
- Product value
- Business outcomes

Every metric should support a decision.

## Analytics Framework

### Acquisition

Question:

How do users discover the product?

Measure:

- Channel source
- Cost
- Conversion

### Activation

Question:

Do users experience initial value?

Measure:

- First success event
- Onboarding completion
- Time to value

### Retention

Question:

Do users continue receiving value?

Measure:

- Returning users
- Usage frequency
- Churn

### Revenue

Question:

Does customer value create business value?

Measure:

- Revenue
- Conversion
- Lifetime value
- Expansion

### Referral

Question:

Do users create organic growth?

Measure:

- Invites
- Shares
- Recommendations

## Event Tracking

Define:

- Event name
- User action
- Purpose
- Related metric

Avoid tracking meaningless activity.

## Data Quality

Ensure:

- Correct implementation.
- Consistent naming.
- Clear ownership.
- Regular review.

## Common Mistakes

- Collecting data without decisions.
- Tracking vanity metrics.
- Ignoring retention.
- Measuring quantity instead of value.

## Founder Academy Standard

Analytics exists to understand customers and improve decisions.
