# Founder AI Agent System

## Purpose

Create specialized AI assistants that increase founder capability.

## Agent Types

- Markets.
- Competitors.
- Information.

### Product Agents

- Requirements.
- Building.
- Testing.

### Growth Agents

- Content.
- Marketing.
- Acquisition.

### Operations Agents

- Workflows.
- Reports.
- Automation.

### Knowledge Agents

- Search.
- Context.
- Memory.

## Requirements

- Clear goals.
- Permissions.
- Verification.
- Monitoring.

## Founder Responsibility

Own:

- Vision.
- Strategy.
- Decisions.

## Avoid

- Uncontrolled agents.
- Missing context.
- Automation without review.

## Founder Academy Standard

AI agents create leverage when they are organized around clear missions.
