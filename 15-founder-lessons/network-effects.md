# Network Effects

## Purpose

Understand how networks create durable competitive advantages.

## Types

### Direct

Users increase value for other users.

### Indirect

Different user groups increase value for each other.

### Data

More usage improves the product.

### Community

Users create knowledge and trust.

## Requirements

- Real user value.
- Participation.
- Trust.
- Incentives.

## Avoid

- Building networks before solving problems.
- Assuming growth equals network effect.

## Founder Academy Standard

A network effect exists when each additional participant increases value for others.
