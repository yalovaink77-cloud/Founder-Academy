# Founder Learning System

## Purpose

Create a system for continuous learning and better decisions.

## Learning Loop

Observe

↓

Experiment

↓

Measure

↓

Learn

↓

Improve

## Sources

- Customers.
- Market.
- Experiments.
- Team.
- Research.

## Practices

- Document decisions.
- Record assumptions.
- Capture lessons.
- Share knowledge.

## Avoid

- Repeating mistakes.
- Information without action.
- Decisions without reflection.

## Founder Academy Standard

Learning speed is a founder competitive advantage.
