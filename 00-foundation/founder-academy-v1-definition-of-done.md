# Founder Academy v1 — Definition of Done

## Purpose

Define what “Founder Academy v1 is complete” means without pretending that a living founder operating system will never evolve.

Founder Academy v1 is complete when the founder can use the repository to move from an idea or existing product to the next evidence-based business decision without depending on one AI conversation or one specific product.

## What V1 Complete Does Not Mean

V1 completion does not mean:

- Every possible founder topic has been exhausted.
- Every marketing platform has a permanent tutorial.
- Every project has completed every lifecycle stage.
- Research stops.
- Playbooks never change.
- New evidence cannot improve the system.

Founder Academy is intentionally a living operating system.

Platform-specific tactics, laws, prices, policies, algorithms, and software interfaces should be researched when needed because they change over time.

---

## Post-V1 Operating Rule

After v1 completion, the default direction is application, not architecture expansion.

For a real project:

1. Run `99-playbooks/project-startup-protocol.md`.
2. Find the earliest consequential evidence gap.
3. Run the matching sprint playbook.
4. Measure the result.
5. Make the founder decision.
6. Preserve project-specific learning in the project's source of truth.
7. Improve Founder Academy only when the application reveals a reusable lesson.
