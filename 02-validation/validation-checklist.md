# Validation Checklist

A product moves to the next stage only if all questions are answered.

## Problem

* [ ] A real problem has been identified.
* [ ] The target customer is clearly defined.
* [ ] Existing alternatives are documented.
* [ ] The problem occurs frequently enough.

## Solution

* [ ] The solution clearly addresses the problem.
* [ ] The value proposition is understandable.
* [ ] Early feedback supports the solution.

## Decision

* [ ] Continue
* [ ] Revise
* [ ] Stop

Validation is complete only when evidence supports moving forward.
