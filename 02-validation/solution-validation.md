# Solution Validation

## Purpose

Solution Validation determines whether the proposed solution solves the validated customer problem well enough to create measurable value.

The objective is to validate product value before pursuing Product-Market Fit.

## Validation Pipeline

1. Validate the problem.
2. Define the solution hypothesis.
3. Build the smallest useful experiment.
4. Test with real users.
5. Observe behaviour.
6. Measure outcomes.
7. Improve.
8. Decide:
   - Continue
   - Iterate
   - Pivot
   - Stop

## Core Principles

- Validate one assumption at a time.
- Behaviour is stronger than feedback.
- Repeated usage is stronger than first impressions.
- Payment is stronger than intention.
- Product value must be measurable.

## Solution Assumptions

Examples:

- Customers understand the product.
- The workflow is intuitive.
- The solution saves time.
- The solution reduces effort.
- Customers complete important tasks.
- Customers return.
- Customers recommend it.
- Customers pay.

## Validation Methods

- Interactive prototype
- Clickable prototype
- Concierge MVP
- Wizard of Oz MVP
- Limited beta
- Paid pilot
- A/B testing
- Usability testing
- Feature experiment

Each experiment should validate one important assumption.

## Behavioural Metrics

Useful metrics include:

- Activation
- Task completion
- Retention
- Time saved
- Error rate
- Repeat usage
- Referral
- Conversion
- Revenue

## False Validation

The following are not sufficient evidence:

- Positive comments
- Likes
- Downloads
- Waiting-list signups
- Feature requests
- Compliments

Real behaviour is required.

## MVP Rule

An MVP should exist only to answer an important product question.

When learning is complete, the MVP should evolve or be replaced.

## Product-Market Fit

Solution Validation does not prove Product-Market Fit.

Product-Market Fit requires:

- Strong retention
- Organic recommendation
- Repeat usage
- Sustainable revenue
- Customer satisfaction

## Scaling Rule

Do not scale until:

- The solution is validated.
- Product-Market Fit is demonstrated.
- Customer acquisition is repeatable.
- Revenue is repeatable.

## Founder Academy Standard

A solution is validated only when customers repeatedly demonstrate that it creates meaningful value through their behaviour.
