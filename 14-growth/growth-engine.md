# Growth Engine

## Purpose

Create a repeatable system for sustainable growth.

## Types

- Sticky
- Viral
- Paid
- Content

## Evaluation

A growth engine should be:

- Repeatable.
- Measurable.
- Scalable.
- Economically sustainable.

## Rules

Do not scale before:

- Product value exists.
- Retention works.
- Customer economics are understood.

## Founder Academy Standard

Growth accelerates value creation; it does not create value by itself.
