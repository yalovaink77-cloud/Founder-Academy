# Product Hunt Launch Playbook

## Before Launch

* [ ] Product page prepared.
* [ ] Logo and gallery uploaded.
* [ ] Tagline finalized.
* [ ] Description reviewed.
* [ ] Website verified.
* [ ] Maker profile completed.

## Launch Day

* [ ] Publish product.
* [ ] Respond to comments.
* [ ] Collect feedback.
* [ ] Monitor traffic.
* [ ] Track signups.

## After Launch

* [ ] Analyze results.
* [ ] Document lessons learned.
* [ ] Prioritize improvements.
* [ ] Follow up with early adopters.
