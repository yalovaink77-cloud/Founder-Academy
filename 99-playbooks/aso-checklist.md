# App Store Optimization Checklist

## Metadata

* [ ] App name optimized.
* [ ] Subtitle optimized.
* [ ] Keywords researched.
* [ ] Description reviewed.

## Visual Assets

* [ ] Icon optimized.
* [ ] Screenshots optimized.
* [ ] App preview prepared.

## Conversion

* [ ] Value proposition is clear.
* [ ] First screenshot communicates the main benefit.
* [ ] Call to action is obvious.

## Measurement

* [ ] Impressions tracked.
* [ ] Store conversion tracked.
* [ ] Downloads tracked.
* [ ] Ratings monitored.
* [ ] Reviews monitored.

ASO is an ongoing optimization process, not a one-time task.
