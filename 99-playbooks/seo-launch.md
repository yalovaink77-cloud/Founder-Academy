# SEO Launch Playbook

## Preparation

* [ ] Keyword research completed.
* [ ] Search intent documented.
* [ ] Landing page created.
* [ ] Metadata completed.
* [ ] Internal links added.
* [ ] Schema markup added.

## Launch

* [ ] Submit sitemap.
* [ ] Verify indexing.
* [ ] Monitor search performance.
* [ ] Fix indexing issues.

## After Launch

* [ ] Track rankings.
* [ ] Update content.
* [ ] Build backlinks.
* [ ] Improve conversion.
