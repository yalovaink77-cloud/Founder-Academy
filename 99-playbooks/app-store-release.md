# App Store Release Playbook

## Product

* [ ] Build completed.
* [ ] Version number updated.
* [ ] Release notes prepared.

## App Store Connect

* [ ] Metadata completed.
* [ ] Screenshots uploaded.
* [ ] App preview uploaded (if applicable).
* [ ] Keywords reviewed.
* [ ] Categories selected.
* [ ] Pricing configured.

## Compliance

* [ ] Privacy Policy
* [ ] Terms of Service
* [ ] App Privacy answers
* [ ] Age rating
* [ ] Support URL

## Submission

* [ ] Archive uploaded.
* [ ] Review requested.
* [ ] Approval monitored.

## After Approval

* [ ] Release verified.
* [ ] Analytics monitored.
* [ ] Crash reports reviewed.
* [ ] User reviews monitored.
