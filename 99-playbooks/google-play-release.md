# Google Play Release Playbook

## Product

* [ ] Release build completed.
* [ ] Version updated.
* [ ] Release notes prepared.

## Google Play Console

* [ ] Store listing completed.
* [ ] Screenshots uploaded.
* [ ] Feature graphic uploaded.
* [ ] App icon verified.
* [ ] Categories selected.
* [ ] Pricing configured.

## Compliance

* [ ] Privacy Policy
* [ ] Data Safety form
* [ ] Content rating
* [ ] Target audience
* [ ] Permissions reviewed

## Release

* [ ] Internal testing
* [ ] Closed testing
* [ ] Production rollout
* [ ] Rollout monitored

## After Release

* [ ] Crash reports monitored.
* [ ] Reviews monitored.
* [ ] Analytics verified.
* [ ] Update backlog created.
