# Advertising Checklist

## Strategy

* [ ] Product-Market Fit confirmed.
* [ ] Target audience defined.
* [ ] Positioning completed.
* [ ] Value proposition validated.

## Campaign

* [ ] Campaign objective defined.
* [ ] Creative prepared.
* [ ] Landing page ready.
* [ ] Budget approved.
* [ ] Tracking configured.

## Measurement

* [ ] Impressions measured.
* [ ] Click-through rate measured.
* [ ] Conversion measured.
* [ ] Cost per acquisition measured.
* [ ] Return on ad spend measured.

## Optimization

* [ ] A/B tests documented.
* [ ] Winning creatives identified.
* [ ] Budget adjusted.
* [ ] Campaign improvements recorded.

Advertising should scale a proven business, not validate an unproven idea.
