## Purpose

Run the first hands-on Lumora usability session with the founder acting as a real first-time user.

This test is observational. The moderator should avoid teaching navigation or explaining intended behavior before the participant attempts each task.

## Testing Rules

- One task at a time.
- Do not coach unless the participant is genuinely blocked.
- Record confusion before helping.
- Record what the participant expected, not only what the product did.
- Product defects, usability defects, trust concerns, wording issues, and missing value signals are all valid findings.
- Do not modify Lumora architecture during the test.
- Any product change is a later decision based on evidence.
