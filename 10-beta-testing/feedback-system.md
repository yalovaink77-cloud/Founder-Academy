# Feedback System

## Purpose

Create a structured system for collecting and acting on user feedback.

## Sources

- Interviews
- Surveys
- Support
- Analytics
- Bugs
- Feature usage

## Categories

- Problem
- Request
- Confusion
- Bug
- Opportunity

## Prioritization

Consider:

- Impact
- Frequency
- Severity
- Strategic value
- Effort

## Avoid

- Building every request.
- Ignoring behaviour.
- Collecting feedback without action.

## Founder Academy Standard

Feedback should produce better decisions, not larger feature lists.
