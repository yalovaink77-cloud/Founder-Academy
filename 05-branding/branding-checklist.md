# Branding Checklist

A brand is ready when:

* [ ] Mission is defined.
* [ ] Vision is defined.
* [ ] Brand promise is clear.
* [ ] Target audience is identified.
* [ ] Brand personality is documented.
* [ ] Visual identity is consistent.
* [ ] Brand assets are complete.
* [ ] Messaging is consistent across all channels.

A strong brand creates trust before the product is experienced.
